# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the Datacendia marketing site, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, email **security@datacendia.com** with:

1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Suggested fix (if any)

We will acknowledge your report within **48 hours** and provide a timeline for a fix.

## Supported Versions

| Version | Supported |
|---------|-----------|
| Current (`master`) | ✅ Yes |

## Responsible Disclosure

We follow a **90-day responsible disclosure policy**. If you report a vulnerability, we will:

1. Acknowledge your report within **48 hours**
2. Investigate and confirm within **7 days**
3. Issue a fix within **90 days**

After 90 days (or sooner, once a fix is deployed), you are free to publicly disclose the vulnerability.

We appreciate responsible disclosure and will credit researchers who follow this process.
